Verify credentials

✓

Upload the original certificate file and enter the certificate ID provided by the institution.

▣

Your document is hashed in your browser. The file itself is not uploaded to the blockchain.

✳

What gets checked?

1
Certificate ID

Finds the certificate record stored on-chain.

2
Document hash

Compares the file's SHA-256 hash with the registered hash.

3
Revocation status

Checks whether the issuing institution has revoked it.

A matching hash confirms the uploaded file matches the registered file. It does not independently confirm the institution's real-world legitimacy.
02

Issue a certificate

Authorized issuer only

Register a certificate's ID and document hash on Ganache. The connected wallet must be authorized as an issuer.

Important

Keep the certificate ID and original file safe. Even a small change to the file creates a different hash.

03

Issuer management

Admin only

Authorize institution wallet addresses or remove an issuer's permission. Only the contract admin can perform these actions.

◇
Connected wallet role

Connect your wallet to check whether it is the contract admin or an authorized issuer.
